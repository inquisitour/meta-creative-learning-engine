# Learnings for the Visual team (concepts and formats)

Based on 80 ads, 4,720,596 impressions (each effect is vs the average level of its attribute, shown with a 95% confidence interval).

## Winner
- visual = gift_scene drives more purchases per impression: +17.2% (95% CI +2.8% to +33.6%), across 15 ads. **Action:** Make 3 more variants in this direction.
- format = carousel drives more purchases per impression: +14.1% (95% CI +3.0% to +26.4%), across 19 ads. **Action:** Make 3 more variants in this direction.
- format = video drives more purchases per impression: +13.2% (95% CI +3.5% to +23.8%), across 34 ads. **Action:** Make 3 more variants in this direction.

## Loser
- visual = product_closeup underperforms: -13.9% (95% CI -22.7% to -4.0%), across 25 ads. **Action:** Stop producing this. Retire running ads that use it.
- format = image underperforms: -22.6% (95% CI -30.1% to -14.4%), across 27 ads. **Action:** Stop producing this. Retire running ads that use it.

## Inconclusive
- visual = lifestyle: no reliable effect yet. Estimate -0.3% (95% CI -10.5% to +11.1%), 25 ads. **Action:** No decision yet. Keep it in rotation so the test can finish.
- visual = unboxing: no reliable effect yet. Estimate -0.7% (95% CI -12.2% to +12.4%), 15 ads. **Action:** No decision yet. Keep it in rotation so the test can finish.
